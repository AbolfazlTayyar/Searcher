# Searcher (Simple LinkedIn Dataset Search Engine)

Implement a simple web application that provides search and filtering capabilities over a LinkedIn user dataset. The focus is on search logic, backend structure, and frontend–backend communication — not on visual/graphic design.

### Input

A ready-made dataset containing approximately 300 LinkedIn profiles (JSON or CSV), including:

- Identity information
- Educational background
- Work experience
- Skills
- etc.

### Task Description

#### 1. Backend

Implement a simple API for:

- Search based on keyword
- Filtering on at least 2 fields of your choice (e.g., skill and job title)
- Using either:
  - ElasticSearch, or
  - Simple search on the database

#### 2. Frontend

A simple page including:

- Search input
- At least 2 filters
- Display of the results list

#### 3. Data

- Design of the data storage structure (SQL or NoSQL)
- Indexing or data preparation for search

### Expected Output

A repo including:

- Backend code
- Frontend code
- A short README including:
  - How to run the project
  - A general explanation of the architecture
  - A brief explanation of the search and filters

### Evaluation Criteria

- Clean API design and code structure
- Correct understanding of search and filter logic
- Proper frontend–backend communication
- Simplicity, readability, and runnability of the project
- Concise and clear documentation

### Important Note

Graphic appearance, a large number of filters, or advanced optimization are considered bonus points, but are not required.
