## What was implemented

Scaffolded the frontend by hand (rather than via `npm create vite`, since the task-01 skeleton already had empty placeholder files for `package.json`, `tsconfig.json`, `App.tsx`, `SearchBar.tsx`, `Filters.tsx`, `ResultsList.tsx` that the CLI's clean-directory check would have rejected):

- `package.json` — React 18, Vite 5, TypeScript 5.6, `@tanstack/react-query`, `use-debounce`; dev tooling for ESLint 9 (flat config), Prettier, and Vitest + React Testing Library (installed now so later test tasks don't need a separate tooling pass).
- `tsconfig.json` / `tsconfig.app.json` / `tsconfig.node.json` — project-references split (app code vs. Vite config), `strict: true` plus `noUnusedLocals`/`noUnusedParameters`/`noFallthroughCasesInSwitch`.
- `vite.config.ts`, `index.html` — standard Vite + React plugin setup.
- `eslint.config.js` — flat config: `@eslint/js` recommended + `typescript-eslint` recommended + `eslint-plugin-react-hooks` recommended rules + `eslint-plugin-react-refresh`, with `eslint-config-prettier` last to disable formatting-related rules.
- `.prettierrc.json` / `.prettierignore` — single quotes, semicolons, 100-char width.
- `src/main.tsx` — mounts `<App />` wrapped in `QueryClientProvider` (TanStack Query wired at the root, per CLAUDE.md).
- `src/App.tsx` — minimal placeholder (`<h1>Searcher</h1>`), no feature components yet.
- `src/vite-env.d.ts` — types `import.meta.env.VITE_API_BASE_URL` so later API-client code doesn't need `any`.
- `frontend/.env.example` — documents `VITE_API_BASE_URL`. Kept in `frontend/` rather than repo root since Vite only loads `.env*` files from its own project root.
- `.gitignore` — added `*.tsbuildinfo` (generated by the new TS project-references build).

Left `SearchBar.tsx`, `Filters.tsx`, `ResultsList.tsx`, and `src/api/` untouched (still empty placeholders from task-01) — those are implemented in tasks 12–13.
